Install on iPhone

  1. Open this page in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen.
  4. Open BallerWatch from the new Home Screen icon.
  5. Tap Enable push inside the installed app.

iPhone Web Push requires the site to be opened as a Home Screen web app.
